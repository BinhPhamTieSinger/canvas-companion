# Canvas Companion Privacy Policy

Effective November 11, 2026.

Canvas Companion is an independent extension for organizing and personalizing VinUniversity's Canvas LMS. It is not affiliated with Instructure, VinUniversity, or BetterCampus.

## Information processed

On the supported Canvas site, the extension can read your numeric Canvas account identifier and timezone, course names and section information, assignments, deadlines, submission flags, calendar events, native syllabus and Home content, and announcements that your signed-in account is authorized to access. It uses course-source text and digests to show changes for review. It does not access grades through a gradebook API, inbox messages, passwords, authentication cookies or session tokens.

You can enter personal classes, examinations, rooms, notes, assignments, projects, milestones and preferences, and choose a background image or URL. These features work in your browser. The publisher does not operate an application server or receive copies of this information.

## Local storage and user control

Background settings, uploaded image bytes, manual academic records, account-scoped source snapshots and short source excerpts/digests are stored locally in the extension's IndexedDB in your Chrome profile. Chrome extension local storage carries revision notifications so open views can update. Chrome synchronization storage is not used. Data is not automatically synchronized to another device or uploaded to the publisher.

The packaged course catalog contains general course/section meeting dates and times, not personal registrations, student lists or authentication details. The optional sample workspace uses fictional data in memory; sample changes reset when reloaded.

You can export local backups, restore missing records, remove a companion background and delete/undo personal records through the product. Backups may contain your academic information and selected image, so keep them private. Uninstalling the extension or deleting its browser storage removes locally stored extension data; export anything you want to keep first.

## Network requests

Live academic integration uses authorized GET requests to https://vinuni.instructure.com through your existing browser session. It never submits assignments, changes grades, alters registration, or sends messages. Automatic refresh is optional and operates while the Canvas dashboard is open. Native course-page and announcement changes are presented for review; the extension does not claim to interpret all academic prose automatically.

Selecting an HTTPS image URL causes the browser to contact that image host, which receives ordinary network information such as an IP address. Upload a local image to avoid third-party image requests. Source links and user-selected external resources open only when you use them. Website/Chrome security and authentication rules remain in effect.

## No sale, advertising or analytics

The extension contains no advertising, analytics, tracking SDKs, remote executable code or publisher telemetry. The publisher does not sell or share personal academic information, use it for advertising or lending decisions, or use it to train AI models. Information is used only to provide the extension's visible academic organization and appearance features. Any handling of Google API data, if applicable, will comply with Google's Limited Use requirements; this extension does not currently request Google API access.

## Contact and changes

For support or privacy questions, use the developer contact or support channel displayed on the Canvas Companion Chrome Web Store listing. Please do not include private academic records, passwords, cookies or tokens in reports. Policy updates will be reflected in this document and the store listing.
