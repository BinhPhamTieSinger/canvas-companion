# Canvas Companion – Privacy Policy

**Last Updated:** November 11, 2026

## 1. Introduction

Canvas Companion is a browser extension designed to enhance the Canvas Learning Management System (LMS) by providing academic dashboards, course schedules, deadline tracking, section discovery, and notifications about changes to course content.

Your privacy is important. This policy explains what information the extension accesses, how it is used, and how it is stored.

## 2. Information We Access

Canvas Companion may access the following information from Canvas pages:

- **Website Content:** Course names, course schedules, class sections, announcements, syllabus content, deadlines, examination information, and academic records.
- **Personally Identifiable Information:** Profile names, profile images, or student identifiers when available and required for displaying Canvas-related information.
- **Authentication Information:** Existing Canvas session information may be used indirectly through the browser's authenticated Canvas session to retrieve authorized course information. The extension does not request or store users' Canvas passwords.

## 3. How We Use Information

Information accessed by Canvas Companion is used exclusively to provide its core functionality:

- Display academic schedules and course information.
- Help students discover available class sections.
- Track deadlines and structured Canvas events.
- Detect changes in announcements, course Home pages, and syllabi.
- Present detected changes for user review.
- Provide an integrated academic dashboard and interface customization.

The extension does not automatically rewrite examination dates, cancellations, or other academic records based on unverified announcements.

## 4. Data Storage

Canvas Companion uses the browser's storage capabilities to retain necessary settings, user preferences, course information, and change-detection baselines.

Stored information supports functionality across browser sessions.

Users can remove locally stored extension information by clearing the extension's stored data or uninstalling the extension.

## 5. Data Sharing and Third Parties

Canvas Companion does not sell personal information or academic data.

Information accessed by the extension is not shared with third parties for advertising, profiling, or unrelated purposes.

Where external services are used for supported academic integrations, information is handled only as necessary to provide the requested functionality.

## 6. Data Security

Canvas Companion is designed to minimize unnecessary data access and use the existing authenticated Canvas session where applicable.

Users should keep their browser and Canvas accounts secure. No method of electronic storage or transmission can guarantee absolute security.

## 7. User Control

Users remain in control of their academic information.

They can:
- Review detected changes before taking action.
- Manage extension preferences.
- Remove locally stored extension data.
- Disable or uninstall the extension at any time.

## 8. Children's Privacy

Canvas Companion is not specifically designed to collect personal information from children under 13.

## 9. Changes to This Policy

This privacy policy may be updated when extension functionality or data practices change. The latest version will be published alongside the extension.
